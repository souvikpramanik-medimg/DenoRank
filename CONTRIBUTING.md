# Contributing to DenoRank

Thank you for your interest in contributing! Bug reports, feature requests and pull requests are welcome.

## Reporting Issues

Please use the issue tracker and include:
- A clear description of the problem
- Steps to reproduce (command and arguments)
- Your environment (OS, Python, PyTorch, diffusers, GPU)
- Error messages / stack traces

## Pull Requests

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature-name`
3. Make your changes and add tests where applicable (`pytest tests/`)
4. Submit a pull request with a clear description of what changed and why

## Code Style

- Follow PEP 8
- Add docstrings to public functions and classes
- Keep commits atomic and descriptive
